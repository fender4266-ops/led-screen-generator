# LED Screen Generator · LED Map

Браузерный инструмент для подготовки LED-экранов: тестовые изображения, композиции из нескольких экранов, карты расключения и инженерные расчёты.

| --- | --- |

Обе версии работают прямо в браузере. Установка и сборка не нужны.

## Что нового

- **Новая компоновка:** настройки слева, превью и экспорт справа; на узком экране блоки располагаются в одну колонку.
- **Разделы настроек:** «Экран и раскладка», «Оформление», «Логотипы». Имя выбранного экрана отображается над настройками.
- **Перетаскивание вкладок:** меняйте порядок экранов, как вкладок в браузере. Выбранный экран, его настройки и координаты сохраняются. С клавиатуры — `Alt + ← / →` на вкладке.
- **Прямая и обратная раскладка:** «В ряд» и «В столбец» чередуют направления при повторных нажатиях. После перестановки вкладок первая раскладка использует их новый порядок.
- **Выравнивание видимых экранов** по верхней, нижней, левой или правой границе композиции.
- **Центральный текст по умолчанию — 80% заполнения круга.** Существующие значения не заменяются; дубликат сохраняет настройки исходного экрана.
- **Обновлённая палитра:** фон `#141414`, зелёные акценты `#2BEE34`. Интерфейс — Manrope, название LED MAP — Sixtyfour Convergence из Google Fonts.

## Визуализация и композиция

| Возможность | Что можно сделать |
| --- | --- |
| Несколько экранов | Добавлять, дублировать, переименовывать, скрывать и удалять экраны |
| Размеры | Задавать физические размеры и параметры кабинетов либо вводить разрешение в пикселях |
| Положение | Вводить X/Y, перетаскивать экраны на превью с прилипанием, раскладывать в ряд или столбец |
| Выравнивание | Совмещать края видимых экранов; скрытые экраны не перемещаются |
| Тестовое изображение | Шахматка или градиент, шесть цветовых пресетов и собственные сохранённые схемы |
| Геометрия и подписи | Крест, круг, название, разрешение и физический размер; цвет, размер текста и подложка |
| Логотипы | Центральный и угловой логотипы с настройками размера, прозрачности, положения и подложки |
| Нестандартная форма | Вырезать кабинеты на превью, инвертировать вырезы или восстановить прямоугольник |
| Превью | Масштабирование, закрепление сверху, сетка, номера кабинетов и границы экранов |
| Экспорт | Общий PNG, отдельный PNG для каждого видимого экрана, Resolume XML |

Перетаскивание **вкладки** меняет порядок экранов, а перетаскивание **экрана на превью** — его положение в композиции.

### Экраны разной высоты на полу или в подвесе

1. Добавьте экраны и задайте размеры каждого.
2. Перетащите вкладки в нужный порядок.
3. Нажмите **«В ряд»**.
4. Для общего пола нажмите **«По низу (пол)»**, для подвеса — **«По верху (подвес)»**.

Выравнивание по верху/низу сохраняет X. Выравнивание по левому/правому краю сохраняет Y. Повторное нажатие «В ряд» заново расставляет экраны, поэтому выравнивание применяйте после раскладки.

## Инженерный расчёт

На второй странице доступны:

- параметры кабинетов и форма экрана из визуализации;
- подбор видеопроцессора автоматически или вручную;
- расчёт загрузки портов и карта расключения с выбором направления;
- потребляемая мощность, вес экрана и расчёт лебёдок по заданным параметрам;
- сохранение карты расключения в PNG;
- экспорт характеристик в PNG с выбором разделов: экран, процессор, мощность, вес и подвес.

## Быстрый старт

1. Откройте **[new version](https://fender4266-ops.github.io/led-screen-generator/new-version/)**.
2. В разделе **«Экран и раскладка»** задайте имя и размеры экрана.
3. Добавьте остальные экраны, настройте порядок и выравнивание.
4. В **«Оформлении»** выберите рисунок, цвета и центральный текст. При необходимости добавьте логотипы.
5. Проверьте композицию на превью и скачайте общий PNG, отдельные изображения или Resolume XML.
6. Для карты расключения и характеристик перейдите в **«Инженерный расчёт»**.

## Сохранение состояния

Порядок экранов, выбранный экран, настройки, логотипы и вырезы входят в сохранение сессии браузера. При обновлении той же вкладки состояние восстанавливается. При новом открытии вкладки приложение начинает новую сессию. Собственные цветовые пресеты сохраняются отдельно в `localStorage`.

Данные не синхронизируются через GitHub или между устройствами. Старая и новая версии на GitHub Pages используют один origin и общие ключи браузерного хранилища — не используйте их как независимые хранилища проектов.

## Запуск локально

```bash
git clone https://github.com/fender4266-ops/led-screen-generator.git
cd led-screen-generator
```

Откройте `new-version/index.html` в браузере. Предыдущая версия находится в корневом `index.html`.

Для загрузки Google Fonts нужен интернет; без него используются резервные системные шрифты. Основные функции приложения работают локально.

## Структура проекта

```text
index.html              # Предыдущая версия
new-version/index.html  # new version — обновлённый LED Map
README.md               # Описание и ссылки на обе версии
```

HTML, CSS и JavaScript находятся в одном файле каждой версии. Отрисовка и PNG-экспорт используют Canvas 2D; сборщик, сервер приложения и фреймворки не требуются.
